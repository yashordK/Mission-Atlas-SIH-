## What is Mission Atlas?

**Mission Atlas** is a comprehensive Swadeshi travel and safety platform built for Indian tourism. It combines offline navigation, AI-powered itinerary planning, blockchain-verified identity, and real-time safety monitoring - all in one platform - to make travel in India safer, smarter, and more self-reliant.

The platform directly supports the **Atmanirbhar Bharat** vision by prioritizing bookings with verified local Indian hotels and businesses, keeping tourist spending within the domestic economy.

---

## The Seven Shields 🛡️

Mission Atlas is built around seven core pillars:

| Shield | Description |
|--------|-------------|
| 🗺️ **Offline Maps** | Navigate without internet - reliable access even in remote areas |
| 🤖 **AI Itinerary** | Personalized travel plans with eco-friendly route suggestions |
| 🔗 **Blockchain ID** | Tamper-proof tourist identity for secure hotel check-ins and bookings |
| 🏨 **Swadeshi Booking** | Verified local hotels and homestays prioritized over foreign chains |
| 🚨 **Safety Alerts** | Real-time AI-powered incident monitoring and 24/7 tourist support |
| 📍 **Geo-fencing** | Prevents unsafe entry and monitors tourist traffic at sensitive sites |
| 📊 **Authority Dashboard** | Real-time monitoring tools for tourism authorities and site managers |

## Tech Stack

### Web Frontend
- **Vite + React + TypeScript**
- **Tailwind CSS**

### Mobile App
- **Expo (React Native)**

### Backend & APIs
- **Node.js / Express**
- **Python** (AI/ML services)

### Blockchain
- **Ethereum** (MetaMask, Ethers.js, Web3.js, Solidity)
- Used for: transparent, tamper-proof tourist identity verification and secure booking transactions

### Database & Cloud
- **Supabase** (PostgreSQL + Auth + Realtime)

## Why It Matters

India's tourism industry contributes significantly to GDP, yet travelers consistently face challenges around safety, unreliable connectivity, and a lack of trust in local services. Mission Atlas directly addresses these gaps:

- **Tourists** get seamless planning, offline access, and verified bookings
- **Local businesses** get more direct bookings without foreign aggregator fees
- **Authorities** get real-time dashboards and geo-fencing tools
- **The economy** benefits from a stronger Swadeshi commerce layer
